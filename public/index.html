On your iPhone

  1. Open the MirrorLink app.
  2. Enter address and code
  3. Tap Start Broadcast. iOS will ask for your permission.

Can’t connect?

  1. If MirrorLink runs on your own computer, keep the iPhone and computer on the same Wi‑Fi. If it’s hosted online, the iPhone only needs internet access.
  2. Allow Local Network access for MirrorLink in iPhone Settings.
  3. Check the address and 8‑character code (codes expire after 10 minutes).
  4. Disable VPNs and guest or “client isolation” Wi‑Fi, which block device‑to‑device traffic.
  5. Allow Node.js through your computer’s firewall when prompted.
Waiting for a connection

How it works. The MirrorLink iPhone app uses Apple’s ReplayKit to capture your screen only after you approve iOS’s broadcast prompt. It sends compressed JPEG frames over a WebSocket to the MirrorLink server, which forwards them to this page. If MirrorLink is hosted online, your screen images pass through that server (over an encrypted connection), so only use a server you trust. Frames are held in memory for a moment and discarded. Nothing is recorded or stored, and no account or personal data is collected. Only screen images (and a timing ping) are transmitted. Stopping the broadcast on the iPhone ends the session immediately.
